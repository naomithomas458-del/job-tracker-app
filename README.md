# Job Tracker App 💼 Paired Project

## About the Project
The Job Tracker App is a web application designed to help users keep track of their job applications, interviews, offers, and rejections in one place.
The app provides a dashboard with application statistics and allows users to add, update, delete, search, and filter their job applications.

## How It Works
Users can add their job applications by entering information such as the company, job title, application date, status, location, employment type, and interview date.
The applications are displayed in a table where users can search, filter, update, or delete their entries.
The dashboard automatically calculates the number of applications, interviews, offers, and rejections, as well as the overall success rate.
The application data is stored in the browser using Local Storage, allowing the information to remain available when the page is reopened.

## Project Highlights
One of the main parts of this project was creating a dashboard that turns the application data into visual statistics. Chart.js is used to display different charts that help users understand their job application progress.
The interview scheduler also allows users to record upcoming interviews and keep track of important interview dates.
